Data engineering project focused on scalable data processing, analytical architectures, and fault-tolerant ingestion.

- Processing and profiling of 3.72M+ NYC TLC trip records.
- Columnar storage, batch processing, and memory optimization.

- Circuit breakers, dead-letter queues, and idempotent ingestion.
- ODCS data contracts and data governance.

**Stack:** Python · Pandas · PyArrow · Parquet · AWS S3 · Glue · Athena · EMR

### [Distributed IoT Monitoring & Control System](https://github.com/felipegtech/monitoring-control-system)

[![CI](https://github.com/felipegtech/monitoring-control-system/actions/workflows/ci.yml/badge.svg)](https://github.com/felipegtech/monitoring-control-system/actions/workflows/ci.yml)

Multithreaded network server engineered from scratch for distributed telemetry and device monitoring.

- Dual-stack IPv4/IPv6 communication over TCP and UDP.
- Custom binary application-layer protocol.
- Thread-safe circular buffers and synchronization.
- Linux PAM authentication and role-based access control.
- Dynamic DNS resolution and exponential backoff.
- 33 automated end-to-end integration tests.
- Deployment on Google Cloud Compute Engine.

**Stack:** C11 · POSIX · pthreads · Linux · Python · GCP

**Stack:** Kubernetes · Docker · GitHub Actions · Node.js · Bash
